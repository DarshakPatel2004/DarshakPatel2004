I work on digital forensics, malware analysis, and threat intelligence tooling. My current focus is automating the parts of DFIR and malware triage that are still manual.

## Projects

**[DroidForensix](https://github.com/DarshakPatel2004/Droidforensix)**: static analysis of Android malware. It extracts C2 infrastructure and attributes malware families from bytecode without executing the app. Family attribution is 64.2% exact match on a 352-sample corrected set. Only about 2.4% of extracted indicators were confirmed as C2, so the README reports those numbers next to the headline counts.

**[VulnForge](https://github.com/DarshakPatel2004/VulnForge)**: threat-intel aggregation. It merges NVD, CISA KEV, and AlienVault OTX into one deduplicated CVE store, scores and ranks by risk, and generates Snort/Suricata and Sigma rules.

**[PhishScope](https://github.com/DarshakPatel2004/PhishScope)**: phishing URL classification with engineered lexical and structural features and an ensemble of classical ML models. Reports 97% accuracy on its dataset.
